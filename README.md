### Dashboard de Calidad — Volkswagen Argentina

Proyecto académico colaborativo orientado al procesamiento, análisis y visualización de indicadores de calidad.

Mis principales contribuciones:

- Desarrollo de indicadores del pilar Cliente.
- Modelado de entidades y acceso a datos.
- Implementación del patrón DAO.
- Importación y procesamiento de informes Excel.
- Visualización de tendencias y pronósticos.
- Comparación de indicadores entre períodos.
- Integración de funcionalidades mediante Git.

**Tecnologías:** C#, ASP.NET Core MVC, PostgreSQL, Razor, JavaScript y Bootstrap.

Repositorio privado por tratarse de un proyecto colaborativo.
